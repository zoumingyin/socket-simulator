## 0. 一句话定义

把 NexSocket Studio 从「本地 Socket 调试工具（v2.x：WS / SIO / HTTP + Mock）」升级为「**多协议服务开发与测试平台**」——支持协议适配器插件化、场景化启停、团队协作（鉴权 / 审计）、可观测（日志 / 压测），并以 SQLite + OpenAPI 3.1 替换当前 JSON + 手工类型。

---

| 维度 | v2.x（现状） | v3.0.0（目标） |
|------|--------------|----------------|
| 定位 | 本地 Socket 调试工具 | 多协议服务开发与测试平台 |
| 协议 | WS / SIO / HTTP + Mock（内嵌） | WS / SIO / HTTP / Mock（MVP）+ TCP / UDP / MQTT / SSE（预留适配器） |
| 存储 | JSON 文件（serde_json） | SQLite + Repository trait（可换 Postgres） |

| 扩展性 | transport 四类写死 | 协议适配器插件化 |

## 5. 关键升级

### 5.1 存储：JSON → SQLite + Repository
- 引入 `Repository` trait：`ServersRepo` / `LogsRepo` / `EventsRepo` / `MockRepo`
- 实现 `SqliteRepository`（sqlx）；预留 `PostgresRepository`
- 迁移：双轨读旧 `config.json` → 导入 SQLite；保留「导出 JSON 备份」能力
- 日志入 SQLite（解决 JSON 日志无限增长、查询慢问题）

### 5.2 安全：鉴权 + 审计
- 首次启动默认生成 admin token，写入配置文件（UI 登录用）
- 角色分级：admin（全权）/ viewer（只读）
- 回环绑定沿用 `127.0.0.1`（不暴露公网）
- 审计日志：关键操作（启停服务、改配置、删规则）写审计表

### 5.3 契约：OpenAPI 3.1 三端同源
- 后端路由生成 OpenAPI 3.1 spec（utoipa 或手写 spec 文件）
- `openapi-typescript` 生成前端类型，替代 / 并存 F-4 的 specta `generated.ts`
- 权威源已定（决策门 2，2026-08-19）：**OpenAPI 3.1 为权威**，F-4 的 specta `generated.ts` 在 v3 迁移期保留作过渡，完成后退役（避免 Rust 类型双出口）

### 5.4 服务统一化（用户 2026-08-13 明确）
- **Service 单一实体**：`protocol` 字段三选一（socketio / websocket / http）；Mock 作为独立配置块（与协议无关）
- **字段注册表驱动**：表单层用字段注册表渲染，避免每协议一套表单
- **发送层**：协议发送器工厂 → SIO event / WS frame / HTTP POST
